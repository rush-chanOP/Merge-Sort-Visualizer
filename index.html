Why it is O(n log n)

Best caseO(n log n)
Average caseO(n log n)
Worst caseO(n log n)
SpaceO(n)

Each split halves the array, so a list of n elements can only be split about log₂ n times before every piece is a single element. That gives log n levels. At each level the merges together look at every element once, which is n units of work. Levels times work per level is n × log n.

Merge Sort never looks at how ordered the input already is, which is why the best, average and worst cases match. The cost is memory: merging two portions needs a temporary array, so extra space grows with n.
